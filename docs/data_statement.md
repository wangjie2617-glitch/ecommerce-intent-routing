# 数据说明与限制

本项目的训练、验证和测试数据均由可复现的中文业务模板生成，仅用于展示多标签分类、阈值调优、路由规则和工程部署能力。

## 数据边界

- 不包含真实客户姓名、手机号、地址、订单号或聊天记录；
- 模板来自常见电商客服语义模式，不复制任何平台的私有语料；
- 训练集与验证/测试集使用不同的表达模板，降低完全相同句式泄漏；
- 订单尾号为程序随机生成并使用掩码形式；
- 指标只反映当前合成数据集表现，不能代表真实生产效果。

## 上线前必须完成

1. 获得合法授权并脱敏真实业务数据；
2. 由业务人员制定标注规范并进行双人标注与冲突仲裁；
3. 重新进行训练、阈值调优和人工验收；
4. 持续监控类别分布、低置信度比例与数据漂移；
5. 对投诉、支付、账户安全等高风险类别保留人工复核。
